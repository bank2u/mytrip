# mytrip

ที่วางแผนเที่ยวของแต่ละทริป และที่เก็บหน้าเว็บแผนเที่ยวสำหรับผู้ร่วมทริป

เว็บ: https://bank2u.github.io/mytrip/

## โครงสร้าง

```
mytrip/
├── index.html                หน้ารวมทุกทริป (ปีล่าสุดอยู่บน)
├── README.md                 ไฟล์นี้
├── CLAUDE.md                 กฎที่ AI ต้องทำตามในโปรเจกต์นี้
├── travelers/                โปรไฟล์กลุ่มผู้เดินทาง ใช้ซ้ำได้ทุกทริป
│   ├── family.md             ครอบครัว 4 คน
│   ├── couple.md             ไปสองคน
│   └── in-laws.md            ครอบครัวแฟน (ยังไม่ได้กรอก)
├── [yyyy]-[place]/           หนึ่งโฟลเดอร์ต่อหนึ่งทริป เช่น 2026-taipei
│   ├── plan.md               แผนตัวจริงของทริป
│   ├── research/             ข้อมูลดิบที่ AI ค้นมา
│   └── index.html            หน้าเว็บให้ผู้ร่วมทริปดู
├── .claude/skills/           ขั้นตอนทำงาน 4 ขั้น
├── .claude/agents/           ผู้ช่วยค้นข้อมูล 2 ตัว
└── kl-trip.html, vietnam.html   ไฟล์ redirect ของลิงก์เก่า ห้ามลบ
```

`yyyy` คือปีที่ทริปเริ่ม ส่วน `place` เป็นตัวพิมพ์เล็กคั่นด้วยขีด

## อะไรขึ้นเว็บ อะไรอยู่แค่ในเครื่อง

repo นี้เป็น public ทุกอย่างที่ commit เปิดสาธารณะ

| อยู่ในเครื่องอย่างเดียว | ขึ้น GitHub |
| --- | --- |
| `travelers/` | `index.html` ทุกหน้า |
| `[yyyy]-[place]/plan.md` | skills, agents, `CLAUDE.md`, `README.md` |
| `[yyyy]-[place]/research/` | |

ไฟล์ฝั่งซ้ายไม่มี backup บน GitHub ควรสำรองเองถ้าสำคัญ
(ยกเว้น `2026-kuala-lumpur/plan.md` ที่อยู่ใน git มาก่อนแล้ว)

หน้าเว็บจะไม่ใส่อายุ ข้อมูลสุขภาพ เลขพาสปอร์ต เลขการจอง หรือที่อยู่บ้าน

## ขั้นตอนใช้งาน

เปิด Claude Code ในโฟลเดอร์นี้แล้วพิมพ์เป็นภาษาไทยได้เลย AI จะเลือก skill เอง
หรือเรียกตรงๆ ด้วย `/ชื่อ-skill` ก็ได้ จะเริ่มที่ขั้นไหนก็ได้ และวนขั้น 2–3 ได้หลายรอบ

| ขั้น | Skill | ใช้เมื่อ | ตัวอย่างคำสั่ง | ได้อะไร |
| --- | --- | --- | --- | --- |
| 1 | `trip-explore` | ยังไม่รู้จะไปไหน | "ต้นมีนา 5 วัน งบคนละ 30,000 ไปกับครอบครัว ไปไหนดี" | ตารางเทียบจุดหมาย 3–5 แห่ง |
| 2 | `trip-plan` | มีจุดหมายและวันที่แล้ว หรือจะแก้แผนเดิม | "วางแผนโอซาก้า 10–15 มี.ค. กับครอบครัว" / "D4 ย้ายวัดไปช่วงบ่าย" | `plan.md` ที่อัปเดตทุกครั้งที่ตัดสินใจ |
| 3 | `trip-verify` | อยากรู้ว่าแผนเป็นไปได้จริงไหม | "ตรวจแผนไทเป" | รายการจุดที่พัง จุดเสี่ยง จุดที่ต้องเช็ก และช่วงที่ควรดูใน Google Maps |
| 4 | `trip-publish` | แผนนิ่งแล้ว | "ทำหน้าเว็บไทเป" | `index.html` ของทริป และอัปเดตหน้ารวม |

หลังขั้น 4 สั่ง "commit และ push" หน้าเว็บจะขึ้นที่
`https://bank2u.github.io/mytrip/[yyyy]-[place]/`

### สถานะใน plan.md

- `[ยืนยัน]` ตกลงหรือจองแล้ว AI จะไม่รื้อ
- `[ต้องเช็ก]` ยังต้องยืนยันกับผู้ให้บริการ
- `[ตัวเลือก]` ตัดสินใจหน้างาน
- หัวข้อ "สิ่งที่ตัดออกแล้ว" คือสิ่งที่ AI จะไม่เสนอกลับมาอีก

`plan.md` เป็นไฟล์เดียวที่ถือว่าเป็นของจริง เอาไปแปะคุยต่อใน AI ตัวอื่นได้
ถ้าไปตัดสินใจที่อื่นมา ให้กลับมาบอกให้อัปเดตไฟล์นี้ด้วย

### ผู้ช่วยค้นข้อมูล (agents)

ใช้เมื่อสั่งให้ใช้ agent เช่น "ใช้ agent ตรวจแผนไทเป" เหมาะกับงานค้นหลายที่พร้อมกัน

- `place-researcher` ค้นเวลาเปิดปิด วันหยุด ราคา การจอง และชื่อสามภาษาของสถานที่
- `route-checker` ตรวจการเดินทางแต่ละช่วง: เวลาจริง ความถี่รถ เที่ยวสุดท้าย ค่าโดยสาร การเดินและบันได

## หน้าเว็บของแต่ละทริป

- แต่ละทริปออกแบบใหม่ ไม่ใช้แม่แบบเดียวกัน ดีไซน์มาจากฤดูกาลช่วงที่ไป
  วัฒนธรรมทางสายตาของประเทศนั้น และธีมของสถานที่
- AI จะบอกแนวคิดดีไซน์สั้นๆ ก่อนลงมือ ถ้าไม่ชอบสั่งเปลี่ยนได้ทันที
- สิ่งที่ไม่ต่อรอง: อ่านง่ายบนมือถือ ตัวหนังสือใหญ่พอ เปิดมาเจอแผนของวันนี้
  กดไปวันอื่นได้ง่าย โหลดเร็ว
- ชื่อสถานที่เขียนเป็น `ไทย · English · ภาษาถิ่น` เช่น `จิ่วเฟิ่น · Jiufen · 九份`
  ถ้าไม่มีชื่อไทยที่นิยม ใช้ `English · ภาษาถิ่น` และลิงก์ไป Google Maps

## กฎภาษา

- AI ตอบเป็นภาษาไทย รายงานระหว่างทำงานแบบสั้น
- ไฟล์ skill, agent และการคุยกันระหว่าง agent เป็นภาษาอังกฤษ
- `plan.md` และหน้าเว็บเป็นภาษาไทย
